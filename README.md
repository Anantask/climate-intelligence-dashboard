# AI-Powered Climate Intelligence Dashboard

An interactive Streamlit dashboard for exploring Indian climate data, visualizing climate trends, and analyzing heatwave risk patterns.

It integrates a trained Random Forest Regression model to estimate Heat Index from climate measurements, along with automatic data insights and model evaluation metrics.

**Technologies:** Python, Streamlit, Pandas, Scikit-learn, Joblib, Plotly.

**Note:** Predictions and risk categories are indicative and are not official heatwave forecasts or government warnings.
